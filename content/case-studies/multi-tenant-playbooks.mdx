## Problem

Managed detection and response was running across multiple client environments. Each environment had its own mix of SIEM, EDR, threat intelligence, and case management tools. Without a shared response path, triage depended on local habit, and the same type of incident could be handled differently from one client to the next. That made the SOC harder to scale.

## Approach

Design and implement multi-tenant SOAR playbooks that standardise incident response across those environments. Connect SIEM, EDR, threat intelligence, and case management tooling into the same automation workflows. Work with SOC, threat intelligence, and detection engineering teams so the playbooks match how investigations actually run. Write the documentation and deliver knowledge-transfer sessions so the workflows are not trapped with one engineer.

## Outcome

The published aim is a SOC that can repeat the same response as more client environments are added, with less dependence on manual triage.
